## 3. AI補正モデル

### 3.1 目的

生のRSSIに含まれる環境固有の系統的歪み（反射・回折・NLOS・アンカー個体差）を除去し、
log-distance path-lossモデルが正確に成り立つ「理想RSSI」に変換する。

### 3.2 モデル構造

```
入力層 (18) → 隠れ層1 (48, ReLU) → 隠れ層2 (24, ReLU) → 出力層 (4, Linear)
```

| 項目 | 値 |
|---|---|
| 入力次元 | 18（現在RSSI 4 + 平均 4 + 標準偏差 4 + ペアワイズ差分 6） |
| 出力次元 | 4（**残差補正 Δ(RSSI)**、各アンカーに対応） |
| パラメータ数 | 18×48 + 48 + 48×24 + 24 + 24×4 + 4 = **2116** |
| メモリ (float32) | ~8.5 KB |
| 推論時間 (Cortex-M4) | < 1 ms |

**残差学習**: MLPは補正済みRSSIを直接出力するのではなく、小さな補正量 $\Delta$ を出力する。

$$
RSSI_{\text{corrected},i} = RSSI_{\text{raw},i} + \Delta_i
$$

初期状態（重みが零近傍）で $\Delta \approx 0$ となり「補正なし」に相当するため、
学習前でもパイプラインが安定動作する。出力は $[-15, +15]$ dB にクランプ。

### 3.3 入力特徴量

```python
# 各アンカー i について（i = A, B, C, D）
rssi_i       # 現在のRSSI値（中央値フィルタ適用済み）
mean_i       # 直近5サンプルの移動平均
std_i        # 直近5サンプルの標準偏差（NLOS/外れ値の指標）

# ペアワイズRSSI差分（6ペア: AB, AC, AD, BC, BD, CD）
diff_ij      # rssi_i - rssi_j
```

**ペアワイズ差分の意義**: 4アンカー間のRSSI差は位置の「シグネチャ」として機能する。
同じ位置では差分パターンが一定であるため、MLPが空間的な位置文脈を捕捉できる。
差分はアンカー全体のゲイン変動（送信電力変化等）をキャンセルする効果もある。

**正規化**: RSSIと平均は $(-60)/20$ でセンタリング、標準偏差は $/5$、差分は $/20$ で正規化。
入力が $[-2, +2]$ 程度の範囲に収まり、ReLUの活性化とXavier初期化が適切に機能する。

### 3.4 学習ターゲット

既知位置 $\mathbf{p}_{\text{true}}$ での計測時、各アンカーへの理想RSSIを算出し、残差をターゲットとする：

$$
RSSI_{\text{ideal},i} = RSSI(d_0) - 10n\log_{10}\!\left(\frac{\|\mathbf{p}_{\text{true}} - \mathbf{p}_{\text{anchor},i}\|}{d_0}\right)
$$

$$
\Delta_{\text{target},i} = RSSI_{\text{ideal},i} - RSSI_{\text{raw},i}
$$

損失関数（L2正則化付き）: 

$$
\mathcal{L} = \frac{1}{4}\sum_{i=1}^{4}(\Delta_{\text{predicted},i} - \Delta_{\text{target},i})^2 + \lambda \|\mathbf{W}\|^2
$$

$\lambda = 0.001$（L2 weight decay）。過学習を防止し、キャリブレーション点が少なくても汎化性能を維持。

### 3.5 補正できるもの／できないもの

| 歪みの種類 | 補正可能性 | 理由 |
|---|---|---|
| 空間的な系統バイアス（反射・回折パターン） | ◎ | 位置に紐づく決定論的歪み |
| NLOS（人体遮蔽等による追加損失） | ○ | 再現性あるパターンは学習可能。動的遮蔽は△ |
| アンカー個体差（$n$, $RSSI(d_0)$のばらつき） | ◎ | 静的な差は完全に吸収 |
| 時間相関ノイズ（スローフェージング） | ○ | 平均・標準偏差の特徴量で対処 |
| 瞬時ランダムノイズ（ファストフェージング） | ✗ | 本質的に不可逆。EKF側で吸収 |

## 4. 運用フロー：既知点キャリブレーション + オンライン適応

### 4.1 概要

任意のフィールドに対応するため、事前の網羅的計測は行わない。
短時間のキャリブレーション（~20秒）で初期モデルを構築し、運用中にオンラインで逐次改善する。

```
[Phase 0: 起動]
    │
    ▼
[Phase 1: キャリブレーション（~20秒）]
    既知の2〜4点を順に通過しながらRSSIを記録
    → (実測RSSI, 理想RSSI) ペアを収集
    → 初期モデルをオフライン学習
    │
    ▼
[Phase 2: 運用 + オンライン適応]
    補正済みRSSI → EKF で位置推定（通常運用）
    推定位置を疑似ラベルとして補正モデルを逐次更新
```

### 4.2 Phase 1: キャリブレーション

| 項目 | 値 |
|---|---|
| キャリブレーション点数 | 9点（3×3グリッド） |
| グリッド座標 | (2,2), (5,2), (8,2), (2,5), (5,5), (8,5), (2,8), (5,8), (8,8) |
| 各点の滞在時間 | ~5秒 |
| 収集サンプル数 | 9点 × 5秒 × 5Hz = **225サンプル** |
| 所要時間 | **約45〜60秒** |

手順:
1. 受信機を既知座標に置く（または立つ）
2. ボタン押下等で記録開始を通知
3. 5秒間RSSIを記録
4. 次の点に移動 → 繰り返し
5. 記録完了後、オンデバイスで初期学習（SGD 120エポック）

**キャリブレーション点数と精度のトレードオフ（シミュレーション結果）**:

| 点数 | 配置 | MAE [m] | 備考 |
|---|---|---|---|
| 4点 | 四隅近く | 1.500 | 最小構成。中央部の補正が弱い |
| 9点 | 3×3グリッド | **1.201** | 推奨。フィールド全域を網羅 |

9点構成はキャリブ時間が約45秒に増えるが、MAEが20%改善。

### 4.3 Phase 2: オンライン適応

運用中、EKFの推定位置を**疑似ラベル**として補正モデルを逐次更新する。

```
推定位置 (EKF出力)
    │
    ├── 信頼度チェック: EKFの推定共分散が閾値以下か？
    │       NO → 更新しない（不確実な推定は使わない）
    │       YES ↓
    │
    ├── 推定位置から理想RSSIを逆算
    │
    └── 補正モデルをSGD 1ステップ更新
         学習率: 低め（0.001程度）で安定性重視
```

**安全策**: 
- 推定が不確実なとき（EKFの共分散行列のトレースが大きい）は更新をスキップ
- 学習率を低く保ち、急激なモデル変化を防止
- オプション: 直近Nサンプルのリプレイバッファで安定化

## 5. EKF設計

### 5.1 状態空間

$$
\mathbf{x}_t = \begin{pmatrix} x \\ y \\ v_x \\ v_y \end{pmatrix}
$$

### 5.2 状態遷移（等速モデル）

$$
\mathbf{x}_{t+1} = F\mathbf{x}_t + \mathbf{w}_t, \quad
F = \begin{pmatrix} 1 & 0 & \Delta t & 0 \\ 0 & 1 & 0 & \Delta t \\ 0 & 0 & 1 & 0 \\ 0 & 0 & 0 & 1 \end{pmatrix}
$$

$\Delta t = 0.2\text{s}$, $\mathbf{w}_t \sim \mathcal{N}(0, Q)$

### 5.3 プロセスノイズ $Q$

```
Q = diag(q_pos, q_pos, q_vel, q_vel)
```

| パラメータ | 静止時 | 歩行時 |
|---|---|---|
| $q_{\text{pos}}$ | 0.01 | 0.1 |
| $q_{\text{vel}}$ | 0.1 | 1.0 |

**移動状態の判定**: 加速度計の分散で切替（分散が閾値以下 → 静止）

### 5.4 観測モデル

観測: 各アンカーまでの推定距離 $z_i = \hat{d}_i$（補正済みRSSIからpath-lossモデルで変換）

$$
h_i(\mathbf{x}) = \sqrt{(x - x_{\text{anchor},i})^2 + (y - y_{\text{anchor},i})^2}
$$

ヤコビアン:

$$
H_i = \frac{\partial h_i}{\partial \mathbf{x}} = \begin{pmatrix} \frac{x - x_i}{d_i} & \frac{y - y_i}{d_i} & 0 & 0 \end{pmatrix}
$$

観測ノイズ: $R = \text{diag}(\sigma_R^2, \ldots)$, $\sigma_R \approx 2\text{–}3$ m（AI補正後は縮小が期待される）

## 9. 学習技法の詳細

### 9.1 過学習対策

キャリブレーション点が9点（225サンプル）と少量のため、過学習対策が不可欠。
以下の組み合わせにより、エポック数を増やしても精度が単調に改善する安定した学習を実現。

| 技法 | 設定値 | 効果 |
|---|---|---|
| **L2 正則化 (weight decay)** | $\lambda = 0.001$ | 重みの発散防止。キャリブ点に過適合せず汎化 |
| **勾配クリッピング** | ノルム上限 5.0 | 外れ値サンプルによる学習の不安定化を防止 |
| **コサインアニーリングLR** | $\text{lr}(t) = \text{lr}_0 \cdot \frac{1 + \cos(\pi t / T)}{2}$ | 序盤は高速学習、終盤は微調整で安定収束 |
| **残差学習** | 出力 = $\Delta$(補正量) | 初期出力が零近傍で安定。フルRSSI予測より学習が容易 |

### 9.2 ハイパーパラメータ選定（A/B テスト結果）

シミュレータ上で条件を揃えたA/Bテストにより最適構成を決定：

| Config | 点数 | 隠れ層 | エポック | L2 | MAE [m] | RMSE [m] | 95th% [m] |
|---|---|---|---|---|---|---|---|
| A | 4 | [32,16] | 50 | なし | 1.500 | 1.740 | 3.050 |
| B | 4 | [32,16] | 100 | なし | 2.100 | 2.372 | 4.300 |
| D | 9 | [32,16] | 100 | なし | 1.533 | 1.743 | 2.999 |
| **E (採用)** | **9** | **[48,24]** | **120** | **0.001** | **1.201** | **1.342** | **2.159** |

- Config B: Loss低下 (1.93) にもかかわらず MAE悪化 (2.100) → **過学習**の典型例
- Config E: L2正則化によりエポック増加で単調改善。最良のMAE/RMSE/95th%を達成

### 9.3 入力正規化の必要性

RSSI値は典型的に -40〜-80 dBm の負値。ReLU活性化関数に負値がそのまま入ると全てゼロに潰れる。
正規化により入力を $[-2, +2]$ 程度に変換し、Xavier初期化と整合させることで学習が安定する。

## 11. チャネルダイバーシティ AI-EKF（新規アルゴリズム）

### 11.1 動機と物理モデル

RSSIの瞬時ランダムノイズは2成分に分解できる：

$$
\sigma^2_{\text{total}} = \underbrace{(1-f)\,\sigma^2}_{\text{周波数共通}} + \underbrace{f\,\sigma^2}_{\text{チャネル独立}}
$$

- **周波数共通成分**（シャドウイング・人体遮蔽・系統誤差）：全チャネルで同一 → 平均化で消せない
- **チャネル独立成分**（マルチパス／ファストフェージング）：BLEチャネル間で無相関 → 平均化で減衰

nRF52833は**80チャネル**を持つため、1推定サイクル内で $N$ チャネルをサンプリングして合成すると：

$$
\sigma_{\text{eff}} = \sigma\sqrt{(1-f) + f/N}
$$

### 11.2 アルゴリズム

```
各推定サイクル:
  for 各アンカー:
    N チャネルで RSSI をサンプリング  (周波数ホッピング)
    combine = median(N チャネルの RSSI)   # 外れ値耐性
  → AI補正付きEKF に投入 (§2〜§5 のパイプライン)
```

合成は**観測層（取得直後）**で行い、下流のAI補正・EKFは無変更。デバイス側ではファームウェアのチャネルホッピングで実現する。

### 11.3 検証結果：クリーン条件では冗長

ガウスノイズのみ（外れ値なし）では、チャネルダイバーシティは**AI-EKFを改善しない**：

| fast_frac | EKF (N=1→10) | AI-EKF (N=1→10) |
|---|---|---|
| 0.3 | 2.96 → 2.68 | 1.79 → 1.87 |
| 0.6 | 2.95 → 2.47 | 1.79 → 1.91 |
| 0.9 | 2.99 → 2.30 | 1.81 → 2.15 |

**理由**：AI-EKFのEKF時間平滑化が既にチャネル独立ノイズを吸収しており、チャネル平均化と冗長。素のEKFには有効だが、最良推定器（AI-EKF）の誤差床は周波数共通成分＋運動ラグで決まる。

### 11.4 検証結果：外れ値下では決定的に有効

2.4GHz ISM帯では、特定チャネルの外れ値（WiFi干渉・パケット破損）が現実に発生する。時間フィルタは急落でラグを起こすが、**チャネル間メディアン合成はこれを除去**する：

| 外れ値確率 | AI-EKF (N=1) | AI-EKF + ダイバーシティ (N=10 median) |
|---|---|---|
| 0.00 | 1.79 | 1.95 |
| 0.02 | 2.32 | **1.96** |
| 0.05 | 3.47 | **1.92** |
| 0.10 | 5.58 | **1.98** |
| 0.15 | 7.75 | **2.10** |
| 0.20 | 9.50 | **2.11** |

（σ=4dB, fast_frac=0.6, 空間バイアス3.0, 1.5 m/s, 10Hz, 6シード平均）

- N=1は外れ値確率に比例して**崩壊**（最大9.5m）
- チャネルダイバーシティは**全外れ値レベルで約2mを維持** → 事実上外れ値耐性を獲得
- 出力: `sim/output/channel_diversity/`（robustness_curve.png, trajectory_compare.png, summary.txt）

### 11.5 結論

チャネルダイバーシティは**瞬時ノイズ低減目的では冗長**だが、**外れ値／干渉耐性のメカニズムとして必須**。micro:bitの2.4GHz運用では干渉が不可避なため、`n_channels ≈ 5–10` のメディアン合成を**標準構成に採用すべき**。実装コストは取得サイクルのチャネルホッピングのみで、下流アルゴリズムは無変更。

**設計パラメータ**（`NoiseConfig`）:
- `n_channels`: 合成チャネル数（推奨 5–10）
- `fast_fading_fraction`: チャネル独立ノイズの分散比（環境依存の仮定値、既定 0.6）
- `channel_combine`: `"median"`（外れ値耐性）推奨 / `"mean"`（純ガウス最適）
